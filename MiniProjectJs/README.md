# LaundryHub

## Description
  LaundryHub is a responsive laundry service booking website developed using HTML, CSS, and JavaScript. The platform allows users to browse laundry services, add services to a cart, calculate total costs, and book services online through an interactive user interface.
The project includes automated email notifications using EmailJS, enabling both administrators and customers to receive booking confirmations. LaundryHub focuses on providing a simple, user-friendly, and efficient laundry booking experience.

## Features
  - Responsive and modern user interface
  - Browse available laundry services
  - Add and remove services from cart
  - Real-time total price calculation
  - Customer booking form with validation
  - Automated booking confirmation emails using EmailJS
  - Newsletter subscription section
  - About Us, Contact, and Important Links sections
  - Interactive and user-friendly design

## Technologies Used
  - HTML5
  - CSS3
  - JavaScript 
  - EmailJS

## How To Run
  1. Download or clone the project.
  2. Keep 'index.html', 'style.css' and 'script.js' in the same folder.
  3. Open 'index.html' in a web browser.
  4. The webpage will display.
