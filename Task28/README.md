# Props in ReactJs

## Description
   A simple webpage displaying the various card with different images, heading and description using props. Each card contains gradient border, image, heading and 
description. title, desc, link are props. Using these props various cards created.

## Features
  1. Cards with image, heading, description.
  2. Cards having gradient border.
  3. Reusable card components.
  4. Card components that are rendered using array of object passed as props.

## Technologies Used
  1. React
  2. Vite
  3. Tailwind CSS

## Steps to create React project
  1. npm create vite@latest (create project)
  2. npm install (install dependencies)
  3. npm run dev (run the project)

## Installation

  1. Clone the repository
    git clone <repository-url>
    
  2. Navigate to the project
    cd project-name
  
  3. Install dependencies
    npm install
  
  4. Start the development server
    npm run dev
