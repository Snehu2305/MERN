# Creating a simple web server with Node.js

## Description
  A beginner-friendly project that demonstrates how to build a basic web server using Node.js (without Express) and implement routing for multiple HTML pages along with serving static assets like images.

## Features
  Create a web server using Node.js core http module
  Route multiple HTML pages (/, /contact, /gallery)
  Serve static files (images)
  Understand request (req) and response (res) handling
  Learn basic backend concepts without frameworks

## Technologies Used
  Node.js
  Core Modules:
    http
    fs
    path
## How to run
  1. Clone the repository
  git clone https://github.com/your-username/simple-node-server.git
  cd simple-node-server
  2. Run the server
  node server.js
  3. Open in browser
  http://localhost:3000
